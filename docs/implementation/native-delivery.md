# 原生应用与浏览器交付

目标：配置完成后，用户在 Linux 的正常新登录终端直接输入应用名；在指纹浏览器管理器直接打开已配置环境。日常不依赖 Agent、手动 PATH、前台代理终端或知彼启动文件夹。

## 完成条件

- 服务端：可恢复地启用原应用名的独立入口，不覆盖原应用二进制；新登录终端命中包裹入口；参数、退出码和项目内当前目录保留；网关常驻并自动恢复；依赖/网关失效不得直连；应用升级后入口仍有效。
- 浏览器端：独立的本机后台连接随登录启动，与远端应用进程解耦；固定回环代理保存到所选指纹环境；重开浏览器仍生效；连接故障不回退直连，恢复后无需重新配代理。
- 配置回读、实际网页出口、故障恢复、恢复原配置分别验收。用户账号登录不由工具代办。
- 连接服务适配 macOS launchd 与 Linux systemd 用户服务。仅浏览器时使用 VPS 已有出口；完整路线使用 Linux 应用的同一个私人网关。浏览器由 Agent 按现场能力使用 API、computer use 或两者结合配置。
- README 与主 Skill 以两个日常入口为中心，维护命令仅给 Agent 使用。发布、回归与实机证据另行记录。

## 新增接入方式

- 私人网关可配置带或不带认证的 SOCKS5 上游。上游连接或认证失败时本次请求停止。独立网关可供纯浏览器使用，也可供另一台工作机接入。
- 已有 SSH Linux 虚拟机可以绑定项目、启动、恢复、传文件和测量隔离入口。PVM 负责一键创建；其他虚拟机管理器负责其自身的建机、共享目录和开关机。
- SSH 项目可单独导出编辑器连接配置和终端入口。项目启动可以跳过浏览器代理，复用已经交付的后台连接。

真实上游、Linux guest、远程编辑器和目标应用环境的联调尚待验收。
