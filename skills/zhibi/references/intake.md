# 了解用户现状并选择下一步

当用户只说「使用知彼」或「带我开始」时，可以这样问。用户已经交代的内容直接沿用。

1. **你现在想做什么？** 例如检查现有环境、注册或开通订阅、配置网页版、配置网页版和 Claude Code，或处理某个报错。也可以直接说卡在哪一步。
2. **你已经有账号了吗？** 涉及开通或账号排查时，区分没有账号、能登录、已订阅，以及已经付款但套餐未到账。只做环境检查时可以跳过。
3. **有 VPS 吗？** 只在用户想配置专用出口或远程工作环境时问。已有 VPS 时请提供地址、用户名和端口，或 SSH 别名和配置的**本地路径**。只有初始密码时走 [首次连接](remote.md#首次连接)，由用户在自己的终端输入密码。用户暂时没有 VPS 时，可以先完成账号指导或本地检查。本地 VM 解决应用运行位置，专用出口仍需单独准备。

| 用户现在需要 | 从哪里接着做 |
| --- | --- |
| 只检查网络或浏览器 | 检查正在用的环境并交付结果。 |
| 注册账号、开通订阅，或付款后套餐没到账 | 使用 [账号与 Google Play](google-play.md)。先看当前页面；已有订阅时核对收据和套餐。 |
| 配置网页版 | 检查现用浏览器和预期出口，按 [浏览器接入](browser.md) 配置并复查。 |
| 配置网页版和 CLI | 复用已配好的网页环境；按 [运行与连接](runtime.md) 准备 Linux 和出口。 |
| 已经配好了，现在有报错 | 看用户实际停在哪一页，或读已有报告、服务状态和回执。从故障点继续。 |

用户选择配置后，再按当前步骤补齐需要的内容：

- 运行位置：优先用户指定的 Linux 服务器；没有则评估本机 PVM 的平台、内存和磁盘。远程路线补齐地址、用户、端口、已有密钥路径及需要的显式 SSH 配置；不擅自复用其他项目的机器或凭据。
- 网络出口：已有专用出口、需要准备的 VPS 出口，或用户明确接受的 direct；与运行位置分开确认。
- 想运行的命令、是否需要持续交互、工作目录和运行用户。
- 是否使用浏览器、具体浏览器和已有配置；远程路线通常为本地浏览器，PVM 路线可在 VM 桌面内运行，不强制指纹浏览器。

选择入口后，说一句当前状态和接下来要做的事，直接开始。先检查已有配置和资源，尽量复用。缺少依赖时按所在系统安排官方安装方式。命令由用户选择，Agent 协助解决安装和路径问题。

私人启动脚本权限 600，凭据不要放在聊天、命令参数或报告中。计划写出会修改的对象和如何恢复；既有授权覆盖的操作不重复确认。
